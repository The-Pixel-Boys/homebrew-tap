# The-Pixel-Boys/homebrew-tap

Homebrew tap for The Pixel Boys tools.

## Install KYA

```bash
brew tap The-Pixel-Boys/tap
brew install shield-kya
```

Or in one line:

```bash
brew install The-Pixel-Boys/tap/shield-kya
```

The formula installs the `@shield-agent/kya` npm package and exposes the `kya` and `shield-kya` binaries.
